# Security

Please report security problems privately, never in a public issue.

- **With a GitHub account:** [Report a vulnerability](https://github.com/mbdrivechains/freebank-phone/security/advisories/new)
  (the repository's Security tab). Only you and the FreeBank team see it.
- **Without one:** on the phone page, **Report a problem or suggest something**, then **A security problem**, then
  send it. It goes to FreeBank's server, where only the FreeBank team reads it. Leave a contact if you'd like a
  reply.

A security problem is anything that could let someone else take coins, read a wallet or its keys, act for a paired
phone, change the page a phone runs, or read what a phone and its desktop say to each other.

Please give us time to fix a problem before you tell anyone else about it.
